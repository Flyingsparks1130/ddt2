DDT2 tournament companion for Windows x64, Steam Umamusume and compatible Hachimi API v3.

- Imports DDT2 teams/players and resolved bracket matchups.
- Runs 4/2/1 scoring across a series, with separate outcome confirmation and publication approval.
- Includes matchup/series OBS sources and manual correction review.
- Retains the original race overlay and offers an optional in-game preview, disabled by default.
- Includes the independent DLL, launcher, Node runtime, artwork, installer and operator guide.

Download **Dominator-Tournament-0.6.0-win64.zip**, extract outside the game folder, close the game/old companion and run **Install.cmd**. See README.txt for fresh Hachimi registration and TOURNAMENT-GUIDE.txt for DDT2 setup. Existing plugin users retain their settings.

Hachimi and horseACT are separate prerequisites. Their binaries/settings are not included or changed. No tournament results, credentials or personal settings are included. Each operator has a separate local store; publishing requires repository permission and explicit review. The optional native preview has not been visually verified on every Hachimi/game build.
