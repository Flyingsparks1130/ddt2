# Event configuration

DDT2 starts November 29, 2026. Dominator, Dominare, Domineer, Dominium and DomiMoon have registered five players each. The bracket, rounds, fixtures, drafts and match times have not been confirmed. The confirmed prize count is six; allocation is not yet set.

The organizer supplied the match format: five trainers per team, six tracks plus a tiebreaker, Unity Cup, a 24-hour training window, one submitted build per trainer used on every track, 4/2/1 podium scoring and a 25-point target. The Rulebook describes the supplied track and Uma draft sequence. Existing scoring defaults already match these values. Official winners still require an organizer decision.

Teams can be registered before a bracket exists. Once a bracket is supplied, the organizer engine retains four-round bracket validation. The tournament's overall round structure has not been announced. Confirm that structure before adding fixtures. Outfit-variant bans and further tiebreaker handling have not been specified; do not invent those rules.

The match panel reads the published index every 60 seconds while the page is visible. This is a view of published results, not a live race feed. Publishing access is unchanged. Followed teams are stored per event in the visitor's browser, with a session-only fallback if storage is blocked.
